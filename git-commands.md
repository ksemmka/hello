# Основные команды Git

Шпаргалка по основным командам git, как ими пользоваться и примеры использования каждой команды.


## 1. `git init` - создание репозитория

**Назначение:** создаёт новый локальный Git-репозиторий в текущей папке.

**Пример использования:**

```bash
mkdir my-project
cd my-project
git init
```


## 2. `git clone` - копирование репозитория

**Назначение:** копирует удалённый репозиторий на компьютер, включая его файлы и историю изменений.

**Пример использования:**

```bash
# Клонировать репозиторий в папку с его именем
git clone https://github.com/ksemmka/repository.git

# Клонировать репозиторий в папку с заданным именем
git clone https://github.com/ksemmka/repository.git my-folder
```


## 3. `git add` - подготовка изменений

**Назначение:** добавляет изменения из рабочей папки в индекс (staging area), подготавливая их к сохранению в коммите.

**Пример использования:**

```bash
# Добавить один конкретный файл
git add README.md

# Добавить все изменения в текущей папке
git add .
```


## 4. `git commit` - сохранение изменений

**Назначение:** сохраняет подготовленные изменения в истории локального репозитория.

**Пример использования:**

```bash
# Создать коммит с описанием изменений
git commit -m "Добавлен файл README"

# Добавить изменённые отслеживаемые файлы и создать коммит
git commit -am "Исправлена опечатка в тексте"
```


## 5. `git push` - отправка изменений

**Назначение:** отправляет локальные коммиты в удалённый репозиторий, например на GitHub.

**Пример использования:**

```bash
# Отправить изменения в удалённую ветку main
git push origin main

# Отправить новую ветку и настроить связь с удалённой
git push -u origin feature-branch
```


## 6. `git pull` - получение изменений

**Назначение:** получает изменения из удалённого репозитория и объединяет их с текущей локальной веткой.

**Пример использования:**

```bash
# Получить и объединить изменения из ветки main
git pull origin main

# Получить изменения из ветки, настроенной по умолчанию
git pull
```
