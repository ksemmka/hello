# Обо мне

Привет! Меня зовут Ксения Краснощекова. Я обучаюсь в магистратуре
по направлению «Прикладная математика и информатика».
Имею математическую и техническую подготовку, интересуюсь
информационными технологиями, анализом данных и автоматизацией процессов.

В процессе обучения получила опыт работы с несколькими
языками программирования: C++, Python, Java и PHP.
Знакома с основами программирования, алгоритмизации
и решения вычислительных задач.

Особенно интересуюсь работой с базами данных.
Имею базовые знания SQL и опыт написания запросов.
Мне интересно изучать принципы организации, хранения
и обработки данных.

Также обладаю следующими навыками:
- Аналитическое и логическое мышление.
- Решение математических и прикладных задач.
- Работа с LaTeX и оформление технической документации.
- Структурирование и анализ информации.
- Самостоятельное изучение новых технологий.

Наиболее интересны направления, связанные с базами данных,
